# Agents for research — seminar

Slides for the Birkbeck Business School research seminar **"Using AI (agents) for research"**
(running title: *Reconsidering AI for research*).

## View

- **Slides:** https://lukaswallrich.github.io/bbs-agents-for-research/slides/

A [reveal.js](https://revealjs.com) deck — use the arrow keys to navigate; press `S` for
speaker notes.

## Structure

```
slides/        the deck
  index.html     reveal.js presentation
  citations.js   citation/bibliography system
  references.json
  assets/        illustrations
```

The repository root is reserved for a companion **resource site** (built during the seminar's
Demo 3), which will be served from `/` while the deck remains at `/slides/`.
