Four habits for using it well

Context

Tell it what you actually want: the goal, the constraints, the audience.

Grounding

Point it at your own sources, not its memory.

Plan/questions

Ask for the plan, or its questions, before you ask for the output.

Verify

Check what it hands back - ideally both manually and automatically.

These apply to any agent you use: Codex (OpenAI) and Claude Code (Anthropic) are in the lead.

Let's GET THIS StARTED

Three demos

  1. Data extraction: power-analysis reporting across recent management papers.
  2. Data analysis: a pre-registration + dataset turned into a clean, reproducible report.
  3. Teaching material creation: build a seminar resource site, and fact-check it.

Then we talk while they run.

Demo 1 · the prompt

Find & extract: power-analysis reporting

  • Goal: how recent management research justifies the effect sizes it powers its studies for.
  • Ground: I provide 2026 articles for 3 ABS 4 journals; agent reads the full text.
  • Extract per paper: type, assumed effect size, how it was justified, α, power, N, software, each with a verbatim source quote.
  • Prepare to verify: "Quote the source for every value; write 'not reported' rather than guessing."

Demo 2 · the prompt

Pre-registration + data → a reproducible report

  • Ground: a pre-registration, data + codebook (ALLBUS 2016)
  • Task: reproduce the pre-registered analysis as a clean Quarto report that renders end to end.
  • Plan: ask me any questions, and document areas to check.
  • Verify: ensure all output is generated by a single commented code file.

Demo 3 · the prompts

Build a resource site for today, then fact-check it

Builder

Build the site from these slides and my email course; follow its style guide and match an existing site's structure.
Every claim cites a real, verified source.

Checker — a fresh agent

Check every claim (file:line) and every DOI; flag invented or stale AI-tool claims, or areas that lack clarity.
Report only, don't fix.

The FOUR habits

Made concrete

  • Context & grounding: full-text retrieval for Demo 1, pre-registration that constrains Demo 2, personal style guide for Demo 3
  • Plan: under-emphasized here, can be developed with AI in chat.
  • Verify: a validated source quote per cell (Demo 1); the agent's results checked against a human analysis (Demo 2); an independent AI fact-checker (Demo 3).

Can I even use AI with my data?

Easy

Published (OA) papers, public datasets: Demos 1 & 3.

With care

Publishable / de-identified data, especially used agentically: ALLBUS in Demo 2.

Never*

Identifiable participant data; (others' sensitive unpublished work).

* without a data processing agreement (and ethics approval), e.g. an enterprise contract or an approved secure environment.

How to get started

and where you just want to get things done (deskilling vs. outsourcing).
